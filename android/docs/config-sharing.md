# 配置分享码

入口：「设置与权限 → 配置导入与导出 → 管理配置分享码」。全程在本机处理，不依赖服务器，不读取或发送账号凭据。

## 范围与替换规则

| 模块 | 范围 | 导入行为 |
| --- | --- | --- |
| 全局策略 | 所有账号共用的评分权重、编组、遗物、商店、事件、开局三槽候选、特别装备与响应速度；不含个人评分 | 整体替换该模块 |
| 个人角色评分 | 精确角色 ID 对应的自定义评分覆盖 | 整体替换个人评分列表，未列出的自定义评分恢复原评分 |
| 刷开局设置 | 当前账号的一份已保存设置，包括默认公会、难度、路线、Boss 条件、次数与撤退开关 | 应用到用户明确选择的本机已有账号，不切换账号 |

未包含或未选择的模块保持原值，其他账号的刷开局设置不变。显式的零分、关闭开关、空列表和候选顺序都保留。事件自定义关闭时，已保存的分支仍随策略分享。

个人评分为空时默认不勾选；主动勾选后，确认界面显示“将清除本机 N 项自定义评分，恢复使用原评分”，还需勾选清除确认才可导入。仅移除个人覆盖，不删除内置评分，也不会将评分设为零。

批量执行目标、完成次数、运行检查点、已读取路线、账号身份、密码、令牌、安装身份、角色数据库、截图和日志均不在分享范围。刷开局默认公会不是批量执行目标，也不会覆盖单独刷开局页的临时选择。

## 导出与导入

1. 停止所有任务。视觉识别、网络刷取、验证码待处理、启动预检、停止收尾和暂停待续均不属于空闲；待续批次可在黎明界页点击“停止待续批次”。
2. 导出时选择模块，刷开局来源固定为当前账号。只导出已保存配置；策略草稿通过既有离页确认先保存或放弃。
3. 点击“生成分享码”，然后“复制分享码”，底部提示“已复制”。运行中不能生成、复制或编辑分享码。
4. 粘贴分享码后点击“导入分享码”，校验通过后选择模块和本机目标账号；查看来源版本、时间及角色引用提示。
5. 点击“预览变更”，确认界面以中文名称显示配置值、公会、Boss、事件分支、开局角色及候选顺序，并列出个人评分新增/修改/移除数量；确认后整体写入。文件损坏、不支持的字段/枚举、未解锁的已知难度或账号不存在会拒绝操作。
6. 本机配置在预览后发生变化时，必须重新预览。导入不触发登录或任务；刷开局条件变化会使旧开局判定失效，需要重新读取当前开局。

本机暂缺的角色引用会明确告知，按精确 ID 保留，不补造角色资料。没有本机账号时，仍可导入全局策略和个人评分。

## 分享码协议

格式：`LABY1.<payload>`。

- `LABY1` 中的 `1` 是协议版本，独立于应用版本。
- 载荷是配置 JSON 的 UTF-8 字节，经单个 GZIP 流压缩后，以不带填充的 Base64URL 编码。
- JSON 包含 `format=labyrinth-config`、`schemaVersion=1`、来源应用版本、导出毫秒时间和显式模块集合。
- 模块键为 `strategy`、`personalScores`、`reroll`；每个选中的策略/刷取模块字段完整，未知或缺失字段不会静默丢弃或用默认值填充。
- 支持粘贴时插入的 ASCII 空格、制表符和换行，不提取聊天文本中的片段，也不接受伪装为其他前缀的内容。
- 原始输入上限 262,144 字符，去除允许空白后的分享码上限 131,072 字符；解压内容上限 524,288 字节，JSON 嵌套上限 16 层，个人评分上限 2,048 项。
- 校验规范 Base64URL、单个 GZIP 流及 CRC/长度、严格 UTF-8、重复 JSON 字段、字段类型、枚举、数值范围和关联约束。额外压缩流、尾随字节和重复集合项均拒绝。
- 当前只支持版本 1；其他版本提示升级或重新导出，不按旧逻辑强行读取。

压缩和编码不是加密，完整性校验也不证明分享者身份。导入外部分享码前应检查撤退、重刷、购买和刷新等变化。

## 保存与恢复

三个模块使用应用私有目录中的统一配置快照。同目录临时写入并同步完成后，通过原子重命名替换正式快照；失败不发布新的内存状态，不采用跨文件部分写入或复制覆盖降级。

首次使用从既有策略与按账号刷开局偏好迁入，并沿用已有响应速度默认值迁移。旧偏好保留，但统一快照存在后不再作为配置真值，也不随分享码输出。

导入前配置和此次导入模块随新配置一起原子保存为一个恢复点，支持重启后“撤销最近一次导入”。恢复需确认、仅空闲可用；恢复为空评分时也需清除确认。手动保存其他配置后恢复点失效，避免撤销时丢弃后续编辑。

任务启动、普通配置保存、账号切换/编辑与分享操作共用准入门：分享占用时拒绝新操作，不排队自动重放任务。任务原有互斥与运行安全门保持有效。

## 验证要点

- 三个模块分别及组合往返，候选顺序、零分、关闭状态和事件分支保持一致。
- 未选择模块、其他账号、内置数据和运行进度不变。
- 空评分默认不选，无清除确认不能提交。
- 错码、超长输入、解压膨胀、重复字段、未知枚举、字段缺失和写入失败不改变原配置。
- 预览后本机配置变化拒绝提交；确认写入后重启保持配置与恢复点。
- 任务启动预检、运行、暂停和停止收尾期间禁止导入导出，完全停止后入口恢复。
- 窄屏、横屏和大字体下可滚动预览、取消与确认；所有导入均不会启动游戏任务。
