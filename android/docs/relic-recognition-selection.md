# 遗物识别与选择调整

## 扫描与层数记录

- 三选一“当前：N”改为异步 OCR，不在整帧识别线程等待文字结果。每个识别器最多保留一个在途小图；跨页面后旧回调不能污染新页面，也不能借重置不断堆积任务。
- 静止区域采用有上限的独立读取，之后复用结果；像素、候选身份、页面或获取代际变化后重新识别。三选一与地图最多读取三次；发现文字不一致时最多再补一次。
- 每次 OCR 结果携带证据 ID 与原始采集时间。新证据须来自独立采集，采集时间晚于已有记录。三选一与商店点击前须有两个不同采集帧确认同一遗物身份；三选一最多等待六秒读取“当前：N”，读不到数值时保持未知。
- 每件遗物每局只能获得一次，按 ID 去重；同 ID 的重复页面保持原有属性与层数，已拥有 ID 从三选一及商店候选中排除。
- 点击前冻结本次预计层数；三选一成功点击后，连续两个新采集帧回到地图才入账，商店以购买完成页为依据。入账按冻结的预计层数结算，期间地图读数用于核对系列层数；短暂 UNKNOWN 过渡保留已经确认的购买身份。
- 首次角色选择确认为新局时，按本局实际公会补入固定基础遗物。游戏接口 `labyrinth/top` 的 `labyrinth_enhance_node_list` 记录账号已获得节点，是已获得判定的依据；明确包含 `31` 才加入该公会第二件遗物。`labyrinth_enhance_information` / `labyrinth_enhance_node` 描述节点定义本身。列表缺失或损坏时只记基础遗物，历史合计仅作估计。
- 公会与节点快照随 Enter ID 保存于路线，已购买节点的空列表与未知状态分开；条件按 Enter ID 隔离，新局或换账号时重新采集。首次选人的入账回执保存在路线中，记录 Enter ID 和历史完整性；重复帧、选人中或角色加入后的同局重启保留已有遗物，真正新局清除旧遗物。后续“迷宫遗物效果”直接发放的随机遗物继续独立识别，ID 由图标识别确定。
- “迷宫遗物效果”奖励列表先用小区域 OCR 两次确认标题，再扫描全部可见图标行，并以资源包中的完整彩色图标确认 ID。选择/随机印记按图标与名称文字判定，首行与其他行同规则处理；特殊、无系列加成遗物照常记录。列表被截断、行消失、图标未确认或提交未完成时保持弹窗打开；八秒仍不完整则停止并保留弹窗。确认后整单按 ID 去重入账，多件同系列累加一次；已更新的地图数值按绝对层数入账。
- 获得后优先复核对应系列的地图左下角数字，最多等待八秒，计时从地图出现开始；第五秒仍未完成时补读一次。两次一致可以确认，三次稳定不等才标为冲突；缺失或不稳定只标为尚未复核。冲突的地图读数只更新冲突状态，已确认的卡片/详情/获取值保持原值，之后读数一致时清除冲突。超时继续路线，系列效果一览仅是手动备选。
- 数据库同时保存唯一遗物及系列总层数/来源，重启恢复已校准值。v4→v5 升级保留每个遗物 ID，删除次数字段，并增加独立开局回执；旧记录标记为未知，完整性以开局回执为准。未掌握完整历史时，历史合计只作可被地图修正的估计；未读到的系列保持未知。角色页面保留已有系列，切换新局后旧代际写入被拒绝。

## 分区域选择

三选一、商店和调试建议共用策略，传入当前区域与主追系列。第 1～3 区补齐加速/会心/守备四层仅是加分项，第 4～5 区明显降低补齐权重；区域未知按后期权重处理。能直接达到原策略的 15 层目标时优先，不被补四层卡住。主追系列是有限加分，不是候选过滤器；明显更好的可用候选允许改变主追方向。

评分结合本次有效增加层数、补四层、接近目标和主追倾向，属层数层面的启发式排序。候选必须通过原有身份识别门槛，点击前还需独立帧复核。沿用商店刷新、价格与按钮识别门槛，数字模板用现有资源。

## 详情兜底边界

支持用户手动打开“系列效果一览”后读取可见系列，兼容屏幕上的“暴击/削弱/崩弱”等名称。弹窗检查期间禁止点击背景地图；可手动滚动，关闭后回到正常路线。标题及左侧名称/数字栏采用小区域异步识别，独立读数一致后才校准；不可见、截断、冲突或无法读取的行不覆盖原记录。

地图最右侧信息圆点、翻页与关闭由用户手动操作；“迷宫遗物”列表里的单件效果仅作展示。详情几何位置按面板适配，实际缩放及滚动效果以实机验证为准。

回归测试覆盖唯一获取、各公会固定初始遗物、第31节点的已获得/未获得/未知状态、路线条件持久化与开局重启、遗物效果直接发放、整单完整性与关闭门禁、预期层数、证据新鲜度、选择过滤、购买过渡、异步取消、数据库事务与迁移。单元测试与构建覆盖上述逻辑；真实识别率与动画时序以设备实机验收为准。
