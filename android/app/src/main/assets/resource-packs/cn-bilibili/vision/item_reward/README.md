# 获得道具界面模板

用于识别连结节点的属性角色印记三选一完成后出现的“获得道具”弹窗。

- `item_reward_title.png`：弹窗标题“获得道具”
- `item_reward_instruction.png`：弹窗说明“获得了以下道具。”
- `item_reward_close.png`：底部“关闭”按钮

运行时必须同时命中标题、说明和关闭按钮，才会将页面分类为 `ITEM_REWARD`。自动化模式只在该页面执行一次关闭按钮动作，识别模式不会点击。

## 迷宫遗物效果弹窗（同一 `ITEM_REWARD` 页面的另一种形态）

开局的“拉比林斯之主”效果会弹出同款弹窗，标题为“迷宫遗物效果”，说明为两行：第一行随效果来源变化，第二行固定为“获得了以下道具。”。判定复用同一组锚点：

- `relic_effect_title.png`：标题“迷宫遗物效果”
- `relic_effect_instruction.png`：说明区域，覆盖两行
- `item_reward_close.png`：底部“关闭”按钮

`relic_effect_instruction.png` 于 2026-10-31 按实机 1280×720 画面重制，文案为“凭借拉比林斯之主的效果，”+“获得了以下道具。”，尺寸 253×43，与该分辨率下取样框 1:1，避免缩放导致的梯度失真。第一行属于可变文案，换成其他效果来源时需要重新截取。
